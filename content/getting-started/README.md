# Getting started

These materials accompany *Numerical Methods for Elliptic Problems*, winter semester 2026/27 at Johannes Kepler University Linz.

## Work in the browser

Open the [course JupyterLite site](https://michaelneunteufel.github.io/2026_WS_numerical_methods_elliptic_problems/lab/index.html?path=index.ipynb). No local installation is required for the regular course exercises.

Start with the [NGSolve and WebGUI check](../notebooks/00_ngsolve_test.ipynb). Then explore the [lecture notebooks](../notebooks/README.md) and [exercise sheets](../exercises/README.md).

Download your work regularly. Browser files are stored in the current browser profile and are not synchronized between devices.

## Work locally

The [NGSolve installation guide (PDF)](ngsolve-installation.pdf) explains pip installation, building from source, and checks for Python, WebGUI, and the C++ compiler.

A local installation is optional. The voluntary [C++ extension test](../exercises/ex01/CppExtensionTest.ipynb) requires a local NGSolve installation and a compatible C++ compiler. Native C++ compilation is unavailable in JupyterLite.

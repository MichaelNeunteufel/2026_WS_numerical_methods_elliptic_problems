# Lecture notes

[Numerical Methods for Elliptic Problems (PDF)](numerical_methods.pdf)

Lecture notes for the winter semester 2026/27 at Johannes Kepler University Linz, by Michael Neunteufel, based on Herbert Egger's 2022 lecture notes.

The current notes cover the introduction, modelling examples, elliptic variational problems, Sobolev spaces, and weak solutions.

Use the [lecture notebooks](../notebooks/README.md) for accompanying examples and the [exercise sheets](../exercises/README.md) to practise the material. Instructions for running NGSolve are under [Getting started](../getting-started/README.md).
